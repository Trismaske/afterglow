# Mobile
1. Edit button still not working, not opening the editor, or even the gallery
2. When the last year review scope is not selected in settings, the "All time unlocks..." text is probably not needed. That can maybe be removed now that the user can select which ones to enable or disable.
3. The pinch zoom in group view works, but it is a bit janky, almost as if the phone realizes suddenly that you want to zoom and not scroll, and then it zooms fine. Compared to the normal phone gallery, its not as smooth, but it works
4. Does the "Best" button in group view do anything? If not, it can be removed
5. On the session page, in old versions, clicking anywhere on the group card would open the group. Now when clicking on a photo within a group, it allows us to change the decision for that photo, but it means that I need to click on the group card without touching a photo if I want to open a group, which makes it quite tricky. I think The old behavior was better, rather open the group and then I can change the decision from within the group instead of making it difficult for me to open the group.
6. In the session view, there are X's in the top corner of photos that have been staged for cull. But the photos that are being kept have no indicator, can they have a tick? Also, when going into the group and looking at a photo, at the bottom it "X staged to cull" if it is staged to cull, but for photos being kept, it doesn't say anything, can it please? Can it also have the X in "X staged to cull" be the same red circle X that you see in the session view? There should also be an indicator for edit with the pencil icon, that way every photo with a decision will have an icon in both session and group views. In the session view, when clicking on a photo thats in a group, the pop up that comes up from the bottom to change a decision, that can be removed, and that way, when clicking on a photo thats in a group, it will open the group again like it should.
7. There should be a way to reset the state of a photo, undo the decision per se. For example, if I have marked for edit, and I click edit again, it should remove the edit status. Photos marked for edit should be automatically kept as well, but only one status/decision is shown, and edit takes precedence.
8. When looking at singles, it would be cool to see a strip of photos that are also in singles to see if there is maybe a similar photo that didn't get grouped because the strictness was too high for example. It would also be nice to be able to scroll though them instead of being stuck on the current photo and being forced to make a decision.
9. Try and align the Singles and Group views a bit more, even use the same underlying layout if possible to keep total LoC and components down, and users stay familiar with layouts and functionality. Almost treating all singles as if they are 1 group? Does it make sense to do that?
10. The new similarity still seems a bit strict to me, but I could get a group to form where only the lighting was slightly different. My personal preference was having it on the loosest setting as I would rather have more groups than less, the groups are very useful. But if the single interface was the same as the groups, it wouldn't matter so much. The custom setting for strictness is great, but not sure what the numbers mean, but it works well and gives us users great flexibility. Going all the way to 64 was way too loose, it seems like similarity was no longer taken into account and just temporal proximity mattered, I guess thats fine for the extreme.
