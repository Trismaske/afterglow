# Feedback from user testing:

## Desktop

### App
- The app is great, but users could not get back to the setting screen. When manually launching the app, they expected to see the settings screen instead of the slideshow starting right away.
- The users really wanted to be able to set the app as their default screensaver. The wanted a button in the settings to do so instead of being able to do it via the windows settings, if possible. The screensaver version should stay in sync with the actual app's settings. They said if the installer is needed to achieve that, its fine.
- Some users did say it takes long to open


### Settings
- Is there a max for cluster cap? Should there be one?
- How can we show the full length of videos? Video cap 0 for full length? Or leave blank?

### Slideshow
- keyboard left and right arrows for going backwards and forwards
- up and down arrow keys on keyboard for restarting or skipping entire moments
- prevent existing screensaver when afterglow is not set as default
- how to get out of the slideshow? any key should go back to the settings menu when manually launched
- Add shortcuts to overlay, difficult for humans to remember

### Other
- What are the existing flag options, could not see them again as we did not know how to get back to the settings. please add an option for "Need to rename" and another for "Need to update date", or perhaps an option for both?


## Mobile

### Editing
When clicking edit, en error comes up saying no "No editor opened Android could not find an app that edits this photo. Install or enable a photo editor and try again." On Samsung phones, it should use the editor built into Samsung Gallery that is normally reached by clicking the pencil icon when viewing the photo in the Gallery. If Afterglow cannot open the editor directly, then it should just open the photo in the Gallery, and the user can manually open the editor by clicking the pencil. I think that behavior can be extended to other phones as well: Instead of this error, try and open the photo up with the built in error, failing that, just open it in the default photo viewer, normally the gallery. The error also mentions "enabling" a photo editor, but not sure if the user is expected to know how to do that? Is that something else we should include in settings?

### Similarity
The strictness of the similarly is way too high. I tested with the use, taking exactly the same photo twice, and they were not grouped in Strictest or Strict. Only in Normal were they grouped. I think Normal should be the new Strictest, Loose works well as Normal, and Loosest is loose enough, maybe even too loose as there were some very different photos that still got grouped together, we assumed it was because of the temporal proximity, which is fine for the loosest setting, where we assume temporal proximity takes precedence over pixel similarity. We can probably stick with those 3, or we can keep 5 levels and you can figure out where they all should be with that guidance. I was also wondering what is happening under the hood here, and if it would perhaps be possible to give the user a slider of sort in the settings panel so they can set the slider to a level that fits bets for them and not be limited to our predefined levels?

### Change decisions
It seems that once a decision has been made, no way for me to change my mind on decisions made
- marked edit, but want to delete

### Sessions
- In a session, no way to review singles first, I am forced to do groups, and forced to start with the first group. The user should be able to choose which groups to do, or be allowed to do singles first instead of being forced into a decision. Doing something, no matter the order, is better than doing nothing.
- When the user clicks "Start Culling" and a popup comes up asking them if they want to "Replaced unfinished session", the two options on the right should be cancel and continue existing, and then on the left you can have the start new option, as it seems that users click this when they want to continue.
- Starting a new session should not discard decisions made in the old session.
- 500 photos seems like too many for a session. it took a while to analyze the photos and after going though 10 groups, the user can be fatigued, and should have a way to end the session to lock in decisions, maybe another button to cull the ones that were selected to be culled etc.
- Perhaps Max photos per session can be set in the settings, with a default of 30 or 50. Additionally, there should be a switch or checkbox that prevents the limit from excluding photos that would otherwise be in a group. For example, if a group of 10 photos was taken at midnight, they can all be included in a group when any photo of that group falls within the bounds of the session.
- There should be a setting to determine if sessions do the oldest [Max photos per session] or the newest

### Compare
- In the compare screen of a group, it only compares 2. When selecting one is better, it should assume the other one can be culled, maybe asking for confirmation with a tick box to not ask again (and a way to reset that in settings?).
- If there were only 2 in the group, and they were compared, and one was selected as better, it should also be labeled as best of the group.
- When there are >2 photos in a group, and you click compare, it puts the current photo in a compare with another photo, but the user has no say in what the other photo is that the current photo is compared with.
- When selecting that one is better in the compare view, it currently seems to have no effect or meaning?
- In Group review, the photos were numbered, but then in compare they are letters (A/B), it would be great if they kept their origin numbers, so if we leave the compare screen and go back to the group, we know which photos within the group were being compared.


## Group review
- It does not seem possible to zoom using the normal 2 finger gesture. It works in the compare seen though, possible to have that in the normal group review?

### Other
1. The icon for settings looks more like an eye or the sun, not like a gear, its not obvious thats the button for settings.
2. Source is in settings, maybe it can be removed from the home screen
3. Review scope options should be customizable in settings. We should be able to choose which ones are shown from the current defaults, but for example, if I go away on a trip from Jan 31 to March 6, i would like to be able to set that to a review scope and give it its own name, like Japan. So maybe start with 2 or 3, and custom takes you to a screen (also available in settings) that allows you to create your own one in that persists. In settings, you should then be able to enable/disable/delete each scope and also reset to default groups and default enabled.
